# Zinab Lab: Ethiopia Rain Tracker (NASA Space Apps 2026, "Dancing with the SARs")

    Zinab (ዝናብ) means "rain" in Amharic.

    ## Goal
    Track rain across Ethiopia, find the places where it is not falling, and explain why, using public data and news.
    Add other useful tools: forecasts, a farmer calendar, SAR imagery and a chat assistant. The site should be easy to
    use and easy to read.

    ## User rules (must follow)
    - Frontend stays in **Astro**. Backend stays in **Python** (FastAPI).
    - **Never write code comments**, in any language, in any file you write or touch.
    - Make it look bold and wild: no generic dashboard theme and no basic unicode symbols (◉ ⌁ ☼ ↗ and so on). Use
    custom SVG icons.
    - Use lots of animation and "wild nature" motifs: Simien mountains, the Ethiopian wolf, geladas, acacia, storms,
    rain particles.
